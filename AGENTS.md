# Diretrizes do Projeto

- **Atualizações Obrigatórias:** Atualizar `DOCUMENTACAO.md`, `PASSOS.md` e `CONTEXTO.md` a cada `feat`, `fix` ou refatoração.
- **Passos Consecutivos:** Marcar `PASSOS.md` com `[x]` para passos concluídos. Aguardar solicitação do usuário antes de iniciar o próximo passo.
- **Commit:** Sempre fornecer a mensagem de commit padronizada no final da resposta.
